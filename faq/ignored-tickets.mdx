## Ignored tickets stay in your main inbox

Not every ticket needs a reply. When your AI Agent decides a message doesn't need a response (for example, a message with no real question, or one outside its scope), it simply doesn't act on it. The ticket is **not moved anywhere** — it stays exactly where it would normally land in your main Gorgias inbox.

<Note>
  This is different from [escalation](/faq/escalated-tickets-gorgias). An escalated ticket gets an internal note and is deliberately left open for a human. An ignored ticket gets no note at all — the agent simply chose not to reply.
</Note>

## Do you need a separate view for ignored tickets?

In most cases, no. Because ignored tickets aren't tagged or moved, there's nothing distinct to filter a view on, and building one adds a step without a clear payoff for most teams.

If you do want visibility into what the agent is choosing not to answer, that's a training question rather than a Gorgias setup question:

- Ask the [AI Manager](/ai-manager) which tickets were recently left unanswered and why — it can reconstruct the reasoning per ticket.
- If you find the agent is ignoring messages it should actually be handling, that usually means a scenario is missing a [protocol](/training/protocols) rather than something to fix in Gorgias.

<Tip>
  If you'd rather have these tickets tagged or routed somewhere specific instead of staying in the main inbox, describe what you want to the [AI Manager](/ai-manager) — this can be set up as a protocol.
</Tip>
