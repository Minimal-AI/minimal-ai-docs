---
title: "James and James"
description: "Connect James and James (ControlPort) to Minimal AI"
---

Connecting James and James lets your AI agents look up orders, tracking, inventory, and returns from ControlPort, their warehouse platform.

## What you'll need

- **API token** — a ControlPort Bearer token for the [James and James Fulfilment API](https://apidocs.controlport.co.uk/api).

## Find your ControlPort API token

<Steps>
  <Step title="Open API Authentication">
    Log in to [ControlPort](https://client.controlport.co.uk/settings/api-authentication-docs) as an account admin and open **Settings → API Authentication**.
  </Step>
  <Step title="Copy the Bearer token">
    Generate or copy your API token. In Minimal AI, paste the token only — Minimal sends it as `Authorization: Bearer …`.
  </Step>
</Steps>

Official API reference: [apidocs.controlport.co.uk/api](https://apidocs.controlport.co.uk/api).

## Connect in Minimal AI

Go to [Dashboard > Integrations](https://gominimal.ai/dashboard/integrations), click **Add an integration > James and James**, and paste your API token.

<Warning>
  Keep your API token secret and only paste it into Minimal AI's James and James integration.
</Warning>
