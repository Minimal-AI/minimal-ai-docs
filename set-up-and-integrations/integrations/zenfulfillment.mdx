Connecting Zenfulfillment lets your AI agents look up orders, tracking, inventory, and returns from Zenfulfillment warehouses.

## What you'll need

- **API key** — a Zenfulfillment API key. Request one from [Zenfulfillment support](mailto:support@zenfulfillment.com). The official API docs are at [docs.zenfulfillment.com](https://docs.zenfulfillment.com/).

## Request your Zenfulfillment API key

<Steps>
  <Step title="Ask Zenfulfillment for an API key">
    Email [support@zenfulfillment.com](mailto:support@zenfulfillment.com) and ask for a production API key. Keys are not self-serve in the merchant dashboard.
  </Step>
  <Step title="Copy the key">
    You will receive a key that is sent as `Authorization: ZF-API <key>`. You can paste either the raw key or the full `ZF-API …` header value into Minimal AI.
  </Step>
</Steps>

## Connect in Minimal AI

Go to [Dashboard > Integrations](https://gominimal.ai/dashboard/integrations), click **Add an integration > Zenfulfillment**, and paste your API key.

<Warning>
  Keep your API key secret and only paste it into Minimal AI's Zenfulfillment integration.
</Warning>
